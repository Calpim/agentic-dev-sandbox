BIZ-001 3 Examples

最低購入金額と割引額の適用

購入金額が5,000円以上の場合に限り1,000円値引きを行い、5,000円未満の場合はエラーメッセージを返却する。

境界値（ちょうど5,000円） 正常系

合計: 5,000円、クーポン: 1,000円引

➜ 適用成功: 請求額 4,000円 (割引 1,000円)
通常の正常適用（高額） 正常系

合計: 12,800円、クーポン: 1,000円引

➜ 適用成功: 請求額 11,800円 (割引 1,000円)
境界値未満（4,999円） 異常系

合計: 4,999円、クーポン: 1,000円引

➜ 拒否: 422 Unprocessable Entity
「あと1円の購入でクーポンが適用できます」
BIZ-002 3 Examples

有効期限とユーザー利用回数の制限

指定された有効期間（JST）内かつ、1ユーザーアカウントにつき1回のみ利用可能とする。

期限最終日の滑り込み 正常系

期限: 10/31 23:59:59、利用時: 10/31 23:59:00

➜ 適用成功: クーポン有効ステータス
期限切れ（1秒超過） 異常系

期限: 10/31 23:59:59、利用時: 11/01 00:00:00

➜ 拒否: 400 Bad Request
「クーポンの有効期限が切れています」
同一ユーザー2回目の利用 異常系

ユーザー: USER-101 (注文履歴 #9822 で使用済)

➜ 拒否: 409 Conflict
「このクーポンはお一人様1回限りのご利用です」
BIZ-003 2 Examples

ポイント・複数クーポンの併用ルール

1回の決済で適用できるプロモーションクーポンは1種類のみ。会員保有ポイントによる値引きとの併用は許可する。

クーポン + ポイント併用 正常系

合計: 6,000円、クーポン: 1,000円、PT利用: 500pt

➜ 適用成功: 請求額 4,500円
(6000 - 1000 - 500 = 4500)
2つ目のクーポン追加入力 異常系

クーポンA適用済の状態で、別クーポンBを入力

➜ 拒否: 409 Conflict
「クーポンは1注文につき1種類のみ有効です」
